# Monthly Maintenance Checklist

Use this for Monthly Care clients.

## Monthly check

- [ ] Website loads
- [ ] Contact form works
- [ ] Phone button works
- [ ] Main links work
- [ ] Hours still correct
- [ ] Services still correct
- [ ] Service area still correct
- [ ] Photos still feel current
- [ ] Any seasonal services need updating?
- [ ] Any new review/testimonial to add?
- [ ] Any outdated announcement to remove?

## Included update examples

- Change hours
- Swap photos
- Update service wording
- Add/remove one small section
- Update phone/email
- Add a testimonial
- Add Google review link
- Small text cleanup

## Not included without quote

- New page
- Full redesign
- New landing page
- Blog writing
- SEO campaign
- Complex form
- Booking system
- Ecommerce
- Emergency work
