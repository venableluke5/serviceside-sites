# Codex Prompt: Review Before Client

Act as a professional web designer reviewing this local service business website before I show it to a real business owner.

Review the client site in:

clients/[client-slug]/

Review for:

- First impression
- Trust
- Visual hierarchy
- Mobile usability
- CTA clarity
- Spacing
- Typography
- Photo usage
- Placeholder or unfinished language
- Service clarity
- Local credibility
- Contact ease
- Scope creep risks

Do not suggest a full redesign unless absolutely necessary.

Give me:

1. Must fix before sending
2. Nice improvements
3. Leave it alone
4. Specific recommended changes
5. A Codex prompt to apply only the must-fix changes
