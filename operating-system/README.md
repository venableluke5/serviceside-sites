# ServiceSide Sites Operating System

ServiceSide Sites builds simple, trustworthy websites for local service businesses.

This operating system keeps each project simple, repeatable, and protected from scope creep.

## Main workflow

1. Find a local service business lead.
2. Build or offer a free homepage preview.
3. Send a soft pitch.
4. If interested, collect client info using the intake form.
5. Create website copy from the intake.
6. Build the site from the local service template.
7. Review the site before sending to the client.
8. Complete up to 2 revision rounds.
9. Collect final payment.
10. Launch.
11. Offer monthly care.

## Core folders

- `clients/` — all client projects
- `templates/` — reusable starter website templates
- `operating-system/` — prompts, checklists, pricing, process docs
- `archive/` — old experiments or retired versions

## Core rule

Do not overbuild.

ServiceSide Sites sells clarity, trust, and easier customer contact — not complicated marketing, full SEO campaigns, or custom software.
