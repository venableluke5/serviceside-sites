# ServiceSide Sites Design Standard

Every website must feel designed for the specific business rather than filled
into a generic template.

## Required Qualities

- Clear visual concept appropriate to the business
- Distinctive typography rather than default system-font styling
- Strong use of authentic business photos whenever available
- Intentional section transitions and visual rhythm
- Responsive layouts designed separately for desktop and mobile
- Strong hierarchy within every section
- Conversion-focused calls to action
- Consistent component styling
- Subtle interaction and motion where it improves the experience
- No unfinished placeholder language

## Avoid

- Repeating the same centered hero on every website
- Generic gradient backgrounds
- Excessive rounded cards
- Random floating shapes
- SaaS-style layouts for local businesses
- Identical section layouts across projects
- Huge amounts of unnecessary text
- Decorative animation without purpose
- Using icons where real imagery would be more persuasive
- Making every section a white rectangle on a slightly gray background

## Design Expectations

Before building, establish:

1. A visual concept
2. A typography pairing
3. An image treatment
4. A spacing system
5. A button style
6. A section rhythm
7. A mobile behavior plan

A site is not approved merely because it is functional.
It must feel cohesive, current, credible, and appropriate to the business.
