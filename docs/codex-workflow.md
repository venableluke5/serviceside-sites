# Required Workflow

## Phase 1: Understand

Read:
- AGENTS.md
- docs/design-standard.md
- docs/copy-standard.md
- the project's project.md
- all available project assets

Do not begin coding yet.

Summarize:
- the business
- target audience
- strongest trust evidence
- current website weaknesses
- missing or uncertain information

## Phase 2: Propose

Before coding, provide:

- one recommended visual concept
- typography direction
- color direction
- image treatment
- proposed page structure
- desktop hero concept
- mobile hero concept
- any information that must not be invented

Wait for approval when requested.

## Phase 3: Build

Build inside the project's site folder.

Use:
- semantic HTML
- maintainable CSS
- lightweight JavaScript
- responsive images
- accessible controls
- purposeful motion

Do not alter unrelated projects or the ServiceSide Sites business website.

## Phase 4: Review

Review the completed site as:

- a professional web designer
- a potential customer
- the business owner
- a mobile user

Identify design weaknesses before making further changes.
